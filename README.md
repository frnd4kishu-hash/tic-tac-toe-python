# Tic Tac Toe (Python)

A two-player tic tac toe game that runs in the terminal, written in Python as a learning project.

## How to run

1. Make sure Python 3 is installed.
2. Open a terminal in this folder.
3. Run:

```
python3 tictactoe.py
```

## How to play

- Player 1 chooses a marker (X or O). Player 2 gets the other one.
- The board is numbered 1 to 9, left to right, top to bottom.
- On your turn, type the number of the square you want.
- First to get three in a row (across, down, or diagonal) wins.
- If all 9 squares fill up with no winner, it's a tie.

## Features

- Two players taking turns on the same computer
- Marker choice (accepts lowercase `x` or `o` too)
- Blocks you from picking a square that's already taken
- Win and tie detection
